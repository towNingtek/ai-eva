# 媒合 MVP 三項決定（#185 定案）

2026-11-23 yillkid 拍板。實作分在 EPIC #176 的子卡。

## 1. 星圖怎麼進正式版

- **比照法規**（#180，見 `docs/regulation-galaxy-plan.md`）：原工具區點「專案媒合」才開星球；同一對話返回再進入接回原任務、不重跑；明確「開始新媒合」才建新任務；完成後用真實判斷結果套試作站驗收過的媒合畫法（B1–B8 衛星、月牙＝需要、互補光流、走進一對）；點衛星由 Eva 說明、不重判。
- **A × 2–4 個指定對象**（2026-11-23：直接 2–4 案）。
- **測試環境：dev.sechome.cc**。dev.sechome.cc 與雲林測試站共用同一個 AI-Eva（`beta-eva.4impact.cc`），所以新版**按租戶（project）開關、只開 sechome**，雲林測試站的專案媒合維持原樣。
- 實作：#203。

## 2. 回答要不要寫回 philosophy

- **由 AI 詢問使用者，明確同意才寫。** 不同意就只留在本次媒合紀錄。
- 只對使用者**自己可管理**的那一案詢問（CMS `list_my_projects` 有這案）；對方專案不問、不寫。
- **附加在原文後並標註來源**（例：「（2026-11-23 補充，經 AI-Eva 媒合補問）」），不改寫原文。
- 寫入走 CMS 新工具 `append_philosophy`（只附加、只寫可管理的專案、`needs_confirm`）。
- 實作：#201（AI-Eva）、town-intelligent/tplanet-multi-tenant#504（CMS 工具）。

## 3. 全程媒合紀錄

- **存放**：AI-Eva 資料庫新開 `matching` schema（與 chainlit、法規分開）：`runs`、`judgements`、`answers`、`events`。
- **保存：永久。**
- **刪除：暫不開放。** 只新增（append-only），程式沒有刪除與修改路徑；更正以新增一筆事件表示。
- **誰能查**：CMS 角色「總管理者」「系統管理者」，以及該租戶 `hosters[0]`（站台擁有者，CMS 保證不可移除）。單位管理者、一般使用者不能查。
- 第一期**不另外告知使用者**。
- 實作：#198。
